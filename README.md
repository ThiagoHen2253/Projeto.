# UniAcolhe
Protótipo web acadêmico de apoio a novos estudantes.

## Como executar
Não precisa de servidor: abra `index.html` no navegador.

## Fluxo
Início -> Avaliação -> Resultado -> Recursos.

## Observação
Os recursos institucionais são categorias genéricas. Para uma entrega real, substitua por informações oficiais da universidade (nomes, horários, contatos e procedimentos).

## Tecnologias
HTML5, CSS3 e JavaScript puro. O progresso/recomendações usam LocalStorage do navegador; não há cadastro.
